# L-SIAMS common-password blocklist
#
# One password per line, compared case-insensitively after trimming. Lines are
# read literally — a line beginning with '#' is only a comment by convention,
# so avoid choosing a password that starts with one.
#
# This list is deliberately small and school-specific rather than a mirror of a
# leaked-credential corpus: the policy already enforces a 12-character minimum,
# character-class variety, and rejection of anything containing the user's own
# name, username or email. What that leaves open is the handful of passwords a
# school's staff genuinely reach for — the school's own name, "attendance",
# variations on the system's name, and keyboard walks long enough to satisfy
# the length rule. Those are what this file blocks.
#
# To harden further, append the 12-plus-character entries from a published list
# such as SecLists' rockyou subset. The lookup streams the file line by line,
# so a large file costs I/O at password-change time only, not memory.
